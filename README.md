# RIAC Açores — protótipo conceptual de redesign

Proposta de redesign do portal da Rede Integrada de Apoio ao Cidadão (Açores), com os serviços utilizáveis na própria plataforma: senha digital com fila em tempo real, agendamento com calendário, lojas com mapa e espera atual, pedidos online, pagamentos e área pessoal.

**Não é o site oficial.** Tempos de espera, vagas, pedidos e pagamentos são simulados; nenhum dado sai do dispositivo de quem o abre.

Ver online: https://miguelbotelhobarros-star.github.io/riac-acores/
